## 1. Test strategy

| Level | Tool | Scope | Runs |
|---|---|---|---|
| Unit | Vitest | Pure functions: age calc, DOB bounds, text guard, mobile normaliser, Zod schemas, `targetGenderFor`, rate-limit window maths | Every commit (CI) |
| Integration | Vitest + real MySQL 8 (Docker locally, service container in CI) | Services and policies against a migrated test DB: discovery exclusions, interest state machine, block effects, purge job, composite FKs | Every PR |
| API contract | Vitest calling Route Handlers | Status codes, error codes, response shapes per doc 08 | Every PR |
| End-to-end | Playwright (Chromium, WebKit, Firefox; mobile viewports Pixel 7 & iPhone 13) | Critical journeys in both locales | Every PR (smoke) / nightly (full) |
| Accessibility | @axe-core/playwright + manual keyboard & screen reader (TalkBack, VoiceOver) | All screens | PR (automated) / before release (manual) |
| Performance | Lighthouse CI on public pages; k6 or autocannon against staging search with 50k demo profiles | NFR-PERF-* | Nightly / before release |
| SEO | Playwright metadata assertions, sitemap/robots tests, schema validator | FR-SEO-* | Every PR |
| Security | IDOR suite, XSS/SQLi payload tests, header checks, dependency audit | NFR-SEC-001 | Every PR + pre-release |
| Manual exploratory | Checklist §4 on real devices | Usability, Bangla copy, low-end Android | Each milestone |

**Test data:** generated by factories inside tests (labelled demo); no real personal data ever used in tests. Clock is controllable (inject `now()`), timezone fixed to Asia/Dhaka in tests.

**Coverage goals:** services and policies ≥ 90 % lines; overall ≥ 75 %. Every FR has at least one TC (see RTM).

## 4. Acceptance test checklist (owner sign-off per milestone)

- [ ] Can register in Bangla on a phone in under 3 minutes without help
- [ ] Under-18 DOB is rejected with a clear message
- [ ] Onboarding can be left and resumed
- [ ] Location selectors show correct, correctly spelt names in both languages
- [ ] Male account only ever sees female profiles, and vice versa
- [ ] Age 25–30 filter includes 25 and 30 year olds
- [ ] Clear filters works; URL can be shared
- [ ] Express interest → accept shows contact to both, nowhere else
- [ ] Block makes both disappear for each other
- [ ] Report sends ops email; ops scripts work
- [ ] Photos never visible when logged out; connections-only works
- [ ] Delete account hides profile immediately
- [ ] No "verified" claims, no fake testimonials, no demo data on production
- [ ] All pages switch language correctly; no missing translations
- [ ] Google "site:" check after launch shows only public pages

## 5. Accessibility checks
Automated axe (TC-109) · keyboard-only (TC-110) · zoom to 200 % without loss · contrast verified for tokens · screen readers: TalkBack (Android Chrome) and VoiceOver (iOS Safari) on register, search, profile, interest dialog · `lang` attributes correct · reduced motion honoured.

## 6. Performance checks
Lighthouse CI budgets (TC-107) · field data from Vercel Speed Insights after launch · search load test (TC-108) · `EXPLAIN` review of discovery queries for each filter combination · bundle analyser on every release · image weight: hero ≤ 150 KB at mobile size.

## 7. Defect severity
**S1** security/privacy leak, under-18 bypass, wrong-gender discovery, data loss — blocks release · **S2** core journey broken — blocks release · **S3** degraded behaviour with workaround · **S4** cosmetic/copy.
